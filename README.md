# InterfazEventosJava

## Aplicación Java de interfaz gráfica y manejo de eventos

Este proyecto corresponde a una aplicación desarrollada en Java para demostrar el manejo de eventos en una interfaz gráfica. La aplicación utiliza la biblioteca AWT y la interfaz `ActionListener` para responder a las acciones realizadas por el usuario.

## Características

- Interfaz gráfica desarrollada con Java AWT.
- Manejo de eventos mediante `ActionListener`.
- Movimiento de un botón mediante `setBounds()`.
- Entrada de datos numéricos mediante `TextField`.
- Cálculo del cuadrado de un número ingresado.
- Contador de clics de un botón.
- Interfaz sencilla, organizada y funcional.

## Requisitos

- Java JDK 8 o superior.
- Visual Studio Code con soporte para Java.
- Sistema operativo compatible con Java.

## Cómo ejecutar

1. Clonar o descargar este repositorio.
2. Abrir el proyecto en Visual Studio Code.
3. Compilar el archivo `InterfazEventos.java`.
4. Ejecutar la aplicación.

```bash
javac -d bin src/InterfazEventos.java
